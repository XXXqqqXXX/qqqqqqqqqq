STEPWISE — запуск на Windows

1. Установите Node.js, если команда npm ещё не работает.
2. Распакуйте архив в отдельную папку.
3. Дважды щёлкните «Запустить STEPWISE.bat».
4. Откройте http://localhost:4173 (страница откроется автоматически).
5. Чтобы остановить сервер, закройте окно консоли.

Для первого запуска интернет нужен для запросов к ИИ и загрузки фотографий категорий.
